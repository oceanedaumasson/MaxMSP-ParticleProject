## About
Calm vs Chaos explores emotional contrast (calm vs. chaos) through real-time generative audio-visual systems. Using Max/MSP and Jitter, I built particle-based visuals and chaotic attractors whose behavior evolves through sound, time-based randomization, and camera motion.
 
## Features
- Real-time generative visual system
- Particle dynamics driven by chaotic attractors
- Audio-reactive parameter mapping, so the visuals respond to sound
- Timed randomization
  
## Built with
Max/MSP, Jitter
